= User interface

NOTE: This documentation was generated with the assistance of AI. Please report any inaccuracies.

The library's only user-facing element is the `GestureBitmapView` component. The repository's `app/` module is a
sample application with a single screen that hosts the view full screen (see xref:sample-app.adoc[Sample app]).

== Accessibility

The repository's `.ui-quality.yml` sets `accessibility: enforce`: automated accessibility checks run with the UI
tests and violations fail them. Screenshots are captured in left-to-right and right-to-left directions and in light
and dark themes.

Navigation between screens is described in xref:ui/navigation.adoc[Navigation flows].
