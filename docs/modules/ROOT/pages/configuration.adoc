== Properties

[cols="2,1,1,4",options="header"]
|===
|Property |Type |Default |Description

|`bitmap`
|`Bitmap?`
|`null`
|Bitmap to display. Setting it resets the transformation; the previously held bitmap is recycled. See also
`setBitmap(bitmap, resetMatrices)` and `setDrawable(drawable)`.

|`displayType`
|`DisplayType`
|`FIT_X_CENTER`
|How the bitmap is initially fitted into the view. Changing it keeps the current on-screen display.

|`animationDurationMillis`
|`Long`
|`200`
|Duration of the scale, scroll and rotate-and-translate animations, in milliseconds. Also used to compute the fling
distance.

|`scrollEnabled`
|`Boolean`
|`true`
|Whether scroll and fling gestures move the bitmap.

|`twoFingerScrollEnabled`
|`Boolean`
|`true`
|Whether scrolling can be done with two fingers.

|`exclusiveTwoFingerScrollEnabled`
|`Boolean`
|`false`
|When `true` with `scrollEnabled` and `twoFingerScrollEnabled`, scrolling requires two fingers. When `true` with
`twoFingerScrollEnabled = false`, scrolling requires exactly one finger.

|`scaleEnabled`
|`Boolean`
|`true`
|Whether pinch gestures scale the bitmap.

|`doubleTapEnabled`
|`Boolean`
|`true`
|Whether a double tap jumps in scale.

|`rotationEnabled`
|`Boolean`
|`true`
|Whether two-finger rotation gestures rotate the bitmap.

|`minScale`
|`Float`
|`1.0`
|Minimum scale, relative to the initial display. Must be greater than 0, otherwise `IllegalArgumentException`.

|`maxScale`
|`Float`
|`10.0`
|Maximum scale, relative to the initial display. Must be greater than 0, otherwise `IllegalArgumentException`.

|`scaleFactorJump`
|`Float`
|`3.0`
|Amount added to the scale on each double tap. Must be at least 1, otherwise `IllegalArgumentException`.

|`minScaleMargin`
|`Float`
|`0.1`
|How far below `minScale` a pinch can go before bouncing back.

|`maxScaleMargin`
|`Float`
|`1.0`
|How far above `maxScale` a pinch can go before bouncing back.

|`leftScrollMargin`
|`Float`
|`100.0`
|Overshoot allowed past the left limit while scrolling, in pixels. Must not be negative, otherwise
`IllegalArgumentException`.

|`topScrollMargin`
|`Float`
|`100.0`
|Overshoot allowed past the top limit, in pixels. Must not be negative.

|`rightScrollMargin`
|`Float`
|`100.0`
|Overshoot allowed past the right limit, in pixels. Must not be negative.

|`bottomScrollMargin`
|`Float`
|`100.0`
|Overshoot allowed past the bottom limit, in pixels. Must not be negative.

|`scrollTensionEnabled`
|`Boolean`
|`true`
|Whether dragging past a scroll limit is progressively slowed down, approaching the margin asymptotically, instead of
following the finger 1:1 until a hard stop at the margin.

|`scrollTension`
|`Float`
|`1.0`
|Amount of tension when `scrollTensionEnabled` is `true`: exponent of the resistance factor
`(1 - overscroll / margin)^scrollTension`. `1` is linear, larger values feel stiffer, values between `0` and `1` feel
softer and `0` removes tension. Must not be negative, otherwise `IllegalArgumentException`.

|`isAntialiasingEnabled`
|`Boolean`
|`true`
|Whether the bitmap is drawn with antialiasing.

|`transformationParameters`
|`MetricTransformationParameters`
|identity
|Scale, rotation and translation applied on top of the base transformation. Setting it enforces no limits.
|===

== Methods

[cols="2,4",options="header"]
|===
|Method |Description

|`setBitmap(bitmap: Bitmap?, resetMatrices: Boolean = true)`
|Sets the bitmap, recycling the previous one. With `resetMatrices = false` the current transformation is kept.

|`setDrawable(drawable: Drawable?)`
|Sets the bitmap from a drawable at its intrinsic size; bitmap drawables are never scaled up by screen density.

|`resetTransformationParameters()`
|Cancels animations and resets the gesture transformation, returning to the initial display.
|===

(`xmlns:app="http://schemas.android.com/apk/res-auto"`). Each one sets the property of the same name.

== MetricTransformationParameters

`data class MetricTransformationParameters(var scale: Double = 1.0, var rotationAngle: Double = 0.0,
var horizontalTranslation: Double = 0.0, var verticalTranslation: Double = 0.0) : Serializable`

== InvalidMatrixException

`class InvalidMatrixException : RuntimeException()`. Thrown by `MetricTransformationParameters.fromMatrix` when the
matrix has perspective terms, unequal scale on both axes, shear, or a zero homogeneous scale.
