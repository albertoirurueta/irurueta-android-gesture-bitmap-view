== Running it

Connect a device or start an emulator (API 26 or later), then from the repository root:

[source,bash]
----
./gradlew :app:installDebug
----

or open the project in Android Studio and run the `app` configuration. Try dragging, flinging, pinching, double
tapping and rotating with two fingers; see xref:gestures.adoc[Gestures] for what each one does.

To experiment with other settings, add attributes from the xref:configuration.adoc#xml-attributes[XML attributes]
table to the layout, for example `app:displayType="center_crop"` or `app:rotationEnabled="false"`.
